# 📝 PWA-приложение "Заметки" с напоминаниями


## 📌 Практика 13 – Service Worker

Реализована регистрация Service Worker, который кэширует статические ресурсы (HTML, JS, CSS) при первом посещении. Добавлен перехват fetch-запросов, благодаря чему приложение загружается из кэша даже при отсутствии интернета. Заметки сохраняются в localStorage и остаются доступными офлайн.

## 📌 Практика 14 – Web App Manifest

Создан файл manifest.json с указанием имени, иконок, темы и режима отображения. В index.html добавлены мета-теги для iOS и Android, что позволяет установить приложение на домашний экран. При установке приложение запускается в отдельном окне без элементов браузера.

## 📌 Практика 15 – HTTPS + App Shell

Настроен локальный HTTPS-сервер с помощью mkcert для корректной работы Service Worker и Push-уведомлений. Реализована архитектура App Shell: каркас (шапка, меню) загружается мгновенно из кэша, а контент подгружается динамически через fetch. Навигация между страницами происходит без перезагрузки.

## 📌 Практика 16 – WebSocket + Push

Подключена библиотека Socket.IO для двусторонней связи в реальном времени. При добавлении заметки уведомление мгновенно появляется у всех открытых клиентов. Добавлены Push-уведомления через VAPID-ключи: после подписки пользователь получает системные уведомления Windows даже при свернутом браузере.

## 📌 Практика 17 – Детализация Push

Добавлена форма для создания заметок с напоминанием (текст + дата/время). На сервере реализовано планирование push-уведомлений через setTimeout. В уведомление добавлена кнопка "Отложить на 5 минут", которая отправляет запрос на сервер и переносит напоминание. Напоминания работают даже при закрытом приложении.

---

## 🎯 Вывод

В результате выполнения практических занятий 13-18 разработано полноценное PWA-приложение для заметок. Оно поддерживает офлайн-режим, устанавливается на устройство, обменивается сообщениями в реальном времени через WebSocket и отправляет push-напоминания с возможностью откладывания. Все ключевые технологии современной веб-разработки (Service Worker, Manifest, App Shell, WebSocket, Push) успешно интегрированы и протестированы.
